# Noctalia configuration (v5)

Noctalia v5 is a different program from the v4 this repo ran until
2026-11-01: a native meson/C++ shell rather than a Quickshell QML one, with a
freeform TOML config and a Luau plugin API. This page used to describe the
"shell profiles" workflow. **That workflow is gone**, and what replaced it is
simpler.

## Where the configuration lives

One file, generated by Nix:

```
modules/desktop/noctalia-hm.nix  ->  ~/.config/noctalia/config.toml
```

The v4 set — `settings.json`, `colors.json`, a `plugins.json`, and a
`settings.json` per plugin — is gone. Colours now come from
`~/.config/noctalia/palettes/<name>.json`, which the Stylix target writes; see
"Stylix owns six values" in `noctalia-hm.nix`.

The settings block is deliberately short. v5 validates the generated file at
**build time** (`programs.noctalia.checkConfig`, default on, runs
`noctalia config validate`), so the safe shape is to write only what differs
from upstream's defaults and let the validator catch mistakes. To see what you
are overriding:

```bash
noctalia config export full     # the complete default schema, ~750 lines
noctalia config export          # just the active config
```

## Profiles are gone

v4 had a `shell-profiles` plugin that stored named profiles under
`~/.config/noctalia/profiles/<name>/` and could switch between them at
runtime. Sabine's machine used one called `simple_mouse`, reapplied on every
rebuild by a `home.activation` block in `modules/users/sabine.nix`.

v5 has no such plugin, and the Luau catalogue has no replacement for it.

What that profile encoded — a minimal, mouse-driven bar with the clock and
battery centred, status on the right, nothing on the left — is now plain
declarative config, branched on the username in `noctalia-hm.nix`. It is no
longer switchable at runtime; changing it is an edit and a rebuild.

The original JSON is kept at `modules/users/sabine-noctalia/simple_mouse/` as
the record of what was actually chosen. It is **not** applied by anything.

## Plugins

Eleven v4 plugins were in use. v5's plugin API is Luau and its official
catalogue is a different set, so ten have no port:

| v4 plugin | v5 |
|---|---|
| `screen-recorder` | `screen_recorder` in the official catalogue |
| `screenshot` | **built in** — `noctalia msg screenshot-region` / `-fullscreen` |
| `clipper` | **built in** — `shell.clipboard_*`, `noctalia msg panel-toggle clipboard` |
| `assistant-panel`, `keybind-cheatsheet`, `mirror-mirror`, `niri-auto-tile`, `screen-toolkit`, `shell-profiles`, `usb-device-manager`, `valent-connect` | no port |

To declare plugins again, use `settings.plugins` — a list of sources plus an
`enabled` list. Nothing in this repo currently sets it.

## Keybindings

v5 replaced the `ipc call` interface with `msg`. The compositor bindings in
`modules/desktop/labwc-hm.nix` were translated wholesale:

| v4 | v5 |
|---|---|
| `noctalia-shell ipc call launcher toggle` | `noctalia msg panel-toggle launcher` |
| `noctalia-shell ipc call sessionMenu toggle` | `noctalia msg panel-toggle session` |
| `noctalia-shell ipc call volume increase` | `noctalia msg volume-up` |
| `noctalia-shell ipc call media playPause` | `noctalia msg media toggle` |
| `noctalia-shell ipc call lockScreen lock` | `noctalia msg session lock` |

`noctalia msg --help` lists the rest. Panel ids are `launcher`, `session`,
`clipboard`, `control-center`, `calendar`, `wallpaper`, `settings`,
`notifications`.
