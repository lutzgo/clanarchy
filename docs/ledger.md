# Interim-rule ledger

Temporary firewall / DNS / routing shims. Every row needs a removal trigger.
Rows are retired only by the PR that actually removes the rule.

The complete, ENFORCED list of hostnames exempt from forward-auth is
`machines/ernst/containers/ingress-policy.nix`, not this file — that one is
consumed by both `traefik.nix` and `authelia.nix`, and `withWan` throws at
evaluation if a router disagrees with it.
